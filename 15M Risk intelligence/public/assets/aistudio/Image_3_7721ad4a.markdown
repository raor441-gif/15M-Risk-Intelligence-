## Brand & Style

This design system delivers an authoritative, high-clarity environment engineered for global compliance, operational resilience, and supply chain intelligence. Designed for risk directors, ESG officers, operations leads, and enterprise auditors, the interface conveys forensic accuracy, algorithmic trust, and friction-free decision velocity.

The aesthetic fuses **Modern Technical Corporate** with **Precision Data Density**:
- Crisp, clinical surfaces anchored by deep obsidian chrome.
- Glowing intelligence signals utilizing bright teal for telemetry feedback and automated computation.
- Functional elegance that elevates high-volume tabular information, geospatial nodes, and compliance chains without visual fatigue.
- Deliberate semantic discipline where bright alert colors are exclusively reserved for verified risk tiers.

## Colors

The system uses an intentional palette designed for dense data interpretation, switching effortlessly between light enterprise workspaces and deep navy chrome navigation:

### Primary & Action Colors
- **Ocean Blue (`#176BCE`)**: Primary actions, link navigations, active component borders, key focus rings, and active tabular filtering.
- **Teal / Intelligence Green (`#19B6A4`)**: Algorithmic triggers, automated engine status nodes, live data flow paths, verification checkmarks, and operational resilience signals.
- **Midnight Navy (`#101B33`)**: High-contrast navigation headers, command shells, primary metric badges, and maximum-contrast display text.
- **Pale Ice Blue (`#EAF3FC`)**: Soft badge fills, container hover treatments, active tree-node selections, and subtle pill card backgrounds.

### Workspace & Surface Canvas
- **Workspace Background (`#F5F8FC`)**: Cool, crisp off-white foundation that eliminates eye strain while maintaining distinction against white card panels.
- **Surface Elevation 0 (`#FFFFFF`)**: Pure white used for primary workspace cards, tabular containers, flyout drawers, and modal sheets.
- **Structural Borders (`#DCE5F2` / `#E2E8F0`)**: Low-contrast borders for crisp delineations between adjacent enterprise modules.

### Strict Risk Semantics
Color is never used purely for decoration. Risk indicators adhere strictly to ISO-compliant enterprise tiers:
- **Critical / Non-Compliant**: `#EF4444` (Text/Stroke: `#DC2626`, Tint: `#FEF2F2`)
- **High / Warning**: `#F59E0B` (Text/Stroke: `#D97706`, Tint: `#FFFBEB`)
- **Moderate / Pending**: `#FBBF24` (Text/Stroke: `#B45309`, Tint: `#FEFCE8`)
- **Controlled / Optimal**: `#10B981` (Text/Stroke: `#059669`, Tint: `#ECFDF5`)

## Typography

The typography is built entirely on **Inter**, configured for extreme typographic clarity across complex layouts:
- **Tight Headings**: Display and headline tiers employ negative letter-spacing (`-0.03em` to `-0.01em`) to create dense, unified structural anchors.
- **Tabular Numerics**: For financial exposure, carbon calculations, audit dates, and coordinate mappings, enable OpenType tabular lining figures (`font-feature-settings: "tnum" 1, "cv05" 1, "cv11" 1`) to guarantee perfect vertical alignment down table columns.
- **Micro-Labels**: Small badges and category identifiers leverage uppercase styling with medium to bold weights (`label-sm`) and positive letter-spacing (`+0.04em`) to maintain legibility at 11px.

## Layout & Spacing

The layout is governed by a responsive 12-column fluid grid paired with an 8pt architectural rhythm (sub-divided to 4pt for micro-controls):

- **Desktop (1440px+)**: 12 columns with `2rem` (32px) gutters and `3rem` (48px) safe margins. Standard multi-pane layout: a 260px collapsible persistent left navigation pane, followed by an expansive primary data workspace.
- **Tablet / Small Desktop (768px - 1439px)**: 8 columns with `1.5rem` (24px) gutters and `2rem` (32px) margins. Left navigation collapses into an icon-rail (64px width) to preserve horizontal data density.
- **Mobile (< 768px)**: 4 columns with `1rem` (16px) gutters and `1rem` (16px) screen margins. Side navigation moves to a full-screen drawer or bottom utility sheet; multi-column analytical grids reflow to single-column card stacks.

## Elevation & Depth

Visual hierarchy is achieved through **refined surface tiers** paired with **ambient tinted shadows**:

1. **Base Layer (Canvas)**: `#F5F8FC` provides a calm, neutral backdrop.
2. **Surface Tier 1 (Cards & Data Tables)**: `#FFFFFF` panels featuring a crisp 1px stroke of `#DCE5F2` and an ambient diffuse shadow: `0 1px 3px rgba(16, 27, 51, 0.04), 0 4px 12px rgba(16, 27, 51, 0.03)`.
3. **Surface Tier 2 (Hovered Cards & Interactive Controls)**: Subtle upward elevation `0 6px 16px rgba(23, 107, 206, 0.08)` paired with an illuminated border shift to `#176BCE` at 30% opacity.
4. **Surface Tier 3 (Dropdowns, Popovers & Context Menus)**: `#FFFFFF` container with `0 10px 24px -4px rgba(16, 27, 51, 0.12), 0 2px 6px -1px rgba(16, 27, 51, 0.06)` and a border stroke of `#DCE5F2`.
5. **Surface Tier 4 (Modals & Audit Overlays)**: Floated centered elements over a dark tinted backdrop (`rgba(16, 27, 51, 0.55)` with 4px backdrop blur), cast with `0 24px 48px -12px rgba(16, 27, 51, 0.25)`.
6. **Intelligence Hub Glows**: For automated engine nodes and focal interactive nodes, subtle radial underglows are applied (`radial-gradient(circle, rgba(25, 182, 164, 0.18) 0%, transparent 70%)`).

## Shapes

The design system maintains a balanced, engineered roundness level (`roundedness: 2`):
- **Base Components**: Inputs, buttons, and individual table selection rows use `0.5rem` (8px).
- **Surface Cards & Data Grids**: Primary modules and analytical containers use `1rem` (16px, `rounded-lg`).
- **Pill Badges & Status Chips**: Tags, telemetry badges, and filter capsules use full roundness (`9999px`) to create distinction between modular panels and actionable tokens.

## Components

### Buttons
- **Primary**: Filled Ocean Blue (`#176BCE`) with white bold text (`label-md`). Hover transitions to `#1459AB`. Focused with a 2px offset ring of `#176BCE`.
- **Intelligence / Secondary Action**: High-contrast Midnight Navy (`#101B33`) with Teal (`#19B6A4`) accent icon and white text. Hover state brightens to `#1D2D50`.
- **Outline / Filter Button**: `#FFFFFF` background, 1px `#DCE5F2` border, text `#101B33`. Hover: `#EAF3FC` background with border `#176BCE`.
- **Ghost / Table Inline Action**: Transparent background, text `#176BCE`. Hover: `#EAF3FC` background with `rounded-md`.

### Status Chips & Badges
- **Format**: Height 24px, padding horizontal 8px, font `label-sm` with tabular numerals.
- **Resilience / Automated (Teal)**: `#E6F7F5` background, `#0D8073` text, `#19B6A4` solid 6px indicator pulse dot.
- **Risk Indicators**: 
  - *Critical*: `#FEF2F2` background, `#DC2626` text, solid red status dot.
  - *High*: `#FFFBEB` background, `#D97706` text, solid amber status dot.
  - *Controlled*: `#ECFDF5` background, `#059669` text, solid green checkmark.

### Input Fields & Controls
- **Inputs**: Height 40px, `#FFFFFF` background, border 1px `#DCE5F2`, text `#101B33`, placeholder `#94A3B8`. Focused: border `#176BCE` with a `0 0 0 3px rgba(23, 107, 206, 0.15)` focus ring.
- **Checkboxes & Radios**: 18px box, border 1.5px `#CBD5E1`. Checked state: filled `#176BCE` with crisp white checkmark or center pip.

### Data Tables
- **Header Row**: `#F8FAFC` background, 36px height, uppercase 11px font (`label-sm`), text `#64748B`, bottom border 1px `#E2E8F0`.
- **Data Rows**: 48px height (compact: 40px), `#FFFFFF` background, subtle bottom border `#F1F5F9`. Hover state activates `#F8FAFC` row highlight with transition `120ms ease`.
- **Numbers / Metrics**: Right-aligned, utilizing `font-feature-settings: "tnum" 1`.

### Surface Cards & Hub Modules
- Clean pure white (`#FFFFFF`) interior, 1px border (`#DCE5F2`), 24px interior padding (`space-lg`), and soft base shadow.
- Actionable cards feature a subtle top border indicator or hover lift to Pale Ice Blue (`#EAF3FC`) border highlights.
